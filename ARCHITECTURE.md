# TAPTAP BOSS Architecture

## Frontend
- React + Vite
- Mobile-first UI
- Socket.IO client
- Neon FX layer

## Backend
- Node.js + Express
- Socket.IO authoritative engine
- Mongo persistence
- Redis-ready cache

## Real-time Loop
1. client tap
2. server validates
3. damage calculated
4. enemy sync
5. reward distribution
6. state reconciliation

## Multiplayer Expansion
- raid rooms
- shared boss damage
- contribution rewards

## Deployment
- frontend on Vercel
- backend on Render/VPS
- Mongo Atlas
- Redis-compatible cache
