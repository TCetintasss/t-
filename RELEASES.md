# Release Strategy

## Semantic Versioning

- major = breaking gameplay/core changes
- minor = feature additions
- patch = fixes and balancing

## Examples

- v1.0.0 initial release
- v1.1.0 shop update
- v1.2.0 raid expansion

## Release Flow

1. build project
2. validate backend
3. generate changelog
4. deploy frontend
5. deploy backend
6. publish release notes
